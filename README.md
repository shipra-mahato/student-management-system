# student-management-system
A College wants to verify if student is ready for placement.

Create a Student class with the following attributes:

studentId
name
age
course
percentage

Requirements:

Create a parameterized constructor.
Create a default constructor.
Override toString().
Create a method isEligibleForPlacement() that returns true if the percentage is 60% or above.
Create 3 student objects and print their details.
Print whether each student is eligible for placement.
